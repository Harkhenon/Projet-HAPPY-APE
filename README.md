# Projet APE (Association Parents d'Élèves)

## Description

Le projet Happy APE permet d'établir un lien entre l'association et les parents d'élèves.
Ce projet est conçu pour être modulaire en adaptant ses modules aux besoins de l'association.

## Fonctionnalités

- **Gestion des membres** : Ajout, modification et suppression des membres.
- **Gestion des événements** : Création, modification et suppression des événements.
- **Gestion des paiements** : Suivi des paiements des membres.
- **Gestion des documents** : Téléchargement et gestion des documents.
- **Gestion des messages** : Envoi et réception de messages entre les membres.
- **Gestion des notifications** : Envoi de notifications aux membres.

## Technologies utilisées

- **Frontend** : React
- **Backend** : Laravel PHP Framework
- **Base de données** : MySQL
- **Authentification** : JWT
- **Hébergement** : Serveur VPS avec PHP et NodeJS

## Installation

1. Cloner le dépôt : `git clone https://github.com/yourusername/yourrepository.git`
2. Installer les dépendances : `composer install` et `npm install`
3. Configurer la base de données : `cp .env.example .env` et modifier les informations de connexion à la base de données.
4. Exécuter les migrations : `php artisan migrate`
5. Lancer le serveur : `php artisan serve` et `npm run dev`
